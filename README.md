## Cómo usarlos con distintas IAs

Los nombres con `/` son etiquetas de esta biblioteca; no se garantiza que una herramienta los reconozca como comandos nativos. Para reutilizarlos, copia la descripción y añade el sujeto, el contexto y el resultado que necesitas. La generación, edición y exportación dependen de las capacidades de la herramienta elegida.

**Ejemplo para fotos:** «Crea una foto profesional de estudio de este perfume, con luz suave y fondo desenfocado. Usa la imagen adjunta como referencia del producto».

**Ejemplo para videos:** «Crea un video de este producto. Haz que la cámara orbite alrededor del sujeto con un movimiento suave. Duración: 6 segundos. Formato vertical».

Si prefieres usar los atajos, proporciona primero sus definiciones en la conversación: «En esta conversación, cuando escriba /productshot, interpreta: foto profesional de estudio del sujeto indicado».

## Organización

- Cada lista agrupa las instrucciones por técnica o finalidad.
- La marca `[Usado]` conserva el historial de los comandos que ya habías probado.
- Se conservan los atajos equivalentes en español e inglés para facilitar su búsqueda.
- Las solicitudes de 4K y 8K dependen de las resoluciones que admita la herramienta.
- Las nuevas categorías, como audio o texto, pueden añadirse cuando haya comandos para ellas.
